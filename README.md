# Project Objective
The objective was to learn how to program a ESP32 microprocessor utilizing ESP-IDF framework.\
The desired skills to learn from this project included first-time ESP32 firmware design and how communication between external modules (e.g. sensors) worked.\
This project is not completed.

# Structure

## Main file
This file contains the base strucutre in terms of thread management and conducts the communication between modules.

## Componenets
This folder contains the attempted drivers developed for the various sensors used during this project. The structure of the folders is based on the ESP-IDF component management system

# NOTE
This project is still very rough with many flaws. It was a first attempt at learning how to design embedded structures.
